# Cocos 浏览器连接插件：文档索引

本目录整理用户提供的 Cocos MCP 资料和当前插件的开发计划。首版安装包已构建，实机证据见 [验收记录](acceptance.md)。

## 当前项目范围

- Cocos Creator 3.8.x，优先在 3.8.6 验证；不能据此宣称全部 3.8.x 小版本已兼容。
- 使用现成 CDP Bridge 及其 relay，连接用户已打开的普通 Chrome 页签。
- Creator 面板和 MCP 客户端共用一个活动目标，MCP 权限按客户端会话隔离。
- 首版提供发现、明确选页、连接、最小页面身份回读、状态、断开及有界恢复。
- 不开发自定义 Chrome 扩展。GameView、原生共存、专用 Chrome、旧 Companion、截图、输入、监控、诊断和 Trace 属于后续能力。

## 来源与证据边界

- 用户最初提供《Cocos MCP 浏览器连接与信息获取·知识库》，随后提供第 01～09 份资料，以及验收、构建与交付资料。最后一部分归档为第 10 篇，其开头可能不是原文全文。
- 第 04 篇来自用户第二个文本附件；原附件缺少标题，按内容整理为 Bridge 文档。
- 参考基线由用户资料标注为 bokeFish 扩展 `0.3.4`、提交 `94530885fd`、Creator `3.8.6`；Bridge 资料标注核对版本为 `cdp-tunnel@3.6.4`。
- 资料中的 `src/**`、`tests/**`、`scripts/**` 都指参考项目 `cocos_mcp/`，当前工作区尚无这些实现。命令仅是参考项目用法，不能直接当成本项目已有命令。
- 飞书源码链接和第三方行为尚未逐项核对；本文不是对相应源码、版本兼容性或历史测试结果的独立认证。
- 原始知识库与第 04 篇附件保存在 [sources](sources/README.md)。其余资料按用户在聊天中提供的正文整理，未声称逐字存档。

## 合并时采用的规则

1. 用户已确认的首版范围优先；完整系统资料用于设计参考，不自动扩大本期范围。
2. 专题资料比最初总览更具体时，保留专题规则并记录差异，见 [开发计划的契约差异](development-plan.md#契约差异与待核对项)。
3. 历史测试成绩、建议实现和本项目实际验证分开记录；未执行的检查明确标记未执行。
4. 本轮仅整理文档，不安装 Bridge、不启动服务、不修改浏览器或系统策略。
